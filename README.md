# Pink Bloom Bakery

A simple bakery website project with an agent-style workflow for improving design, frontend structure, and content quality.

## Project Structure

```text

├── agents/
│   ├── design-agent.md
│   ├── frontend-agent.md
│   └── content-agent.md
├── assets/
```

## Agent Workflow

This project is organized so each agent has a clear job:

- **Design Agent** — improves visual style, layout, spacing, color system, and overall polish
- **Frontend Agent** — handles HTML/CSS/JS structure, responsiveness, code cleanup, and maintainability
- **Content Agent** — improves headings, selling copy, product descriptions, CTA text, and brand voice

## How to work on this project

1. Start with `design-agent.md` when you want the website to look more premium.
2. Use `frontend-agent.md` when you want to refactor or expand the code.
3. Use `content-agent.md` when you want better copywriting or conversion text.
4. Keep assets organized under `assets/`.
